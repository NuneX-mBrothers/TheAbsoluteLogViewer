Каждую загрузку можно проверить

Сборки Standalone и Portable подписаны цифровой подписью с меткой времени. В каждом выпуске публикуется SHA-256 в version.json, и приложение сверяет его перед установкой любого обновления по HTTPS. Изменённые файлы отклоняются автоматически.

И это не только наши слова: Softpedia Labs проверила программу независимо и присвоила ей знак 100% Clean — без шпионского и рекламного ПО и вирусов.
Для тех, кто живёт в логах

Всё, чего вам не хватало в tail -f.

Не только .log — любой текстовый лог

Логи Linux и Unix бывают какими угодно: syslog, messages, ротированный auth.log.1, файлы вообще без расширения. Задайте шаблоны имён — и программа будет следить за каждым подходящим текстовым файлом, а двоичные пропустит сама.

Слежение за логами в реальном времени

Следите за файлами логов вживую — новые строки появляются мгновенно. Прокрутка вверх ставит на паузу, возврат вниз продолжает.

Независимые вкладки

Каждая вкладка — отдельное рабочее место со своим набором логов, разделением, поиском и порядком. Следите за разными проектами одновременно, не путая их.

Сравнение в двух панелях

Две независимые панели, два файла рядом — у каждого свой поиск и своё слежение.

Слежение за .csv по столбцам

Ещё .csv/.tsv, но в виде таблицы — заголовок файла становится названиями столбцов, а новые строки появляются вживую. Запятая, точка с запятой или табуляция определяются автоматически.

Подсветка по regex

Раскрашивайте целые строки или отдельные слова. Помощники для границ слова и предпросмотр вживую.

Предпросмотр контекста

Наведите курсор на отфильтрованную строку, чтобы увидеть соседние строки из полного, неотфильтрованного файла.

Встроенное автообновление

Standalone и Portable обновляются сами — с проверкой целостности по HTTPS.

Вопросы

Это правда бесплатно?

Да — freeware, для личного и коммерческого использования. Без учётной записи и без cookie; приложение отправляет только анонимную статистику установок и обновлений, и её можно отключить.

Windows просит подтверждение при запуске. Почему?

Подпись свежая, а Windows нужно время, чтобы узнать нового издателя — с файлом всё в порядке. Нажмите «Подробнее» → «Выполнить в любом случае». Установка ClickOnce имеет собственную подпись и может по-прежнему показывать «Неизвестный издатель». С каждым выпуском публикуется SHA-256, который можно проверить.

Какую сборку выбрать?

ClickOnce — если хотите автообновления без забот (нужен Microsoft Edge). Standalone — если .NET 10 уже установлен. Portable — если не хотите ничего устанавливать.

Где исходный код?

Программа бесплатная, а исходный код закрыт, но сообщения об ошибках и пожелания всегда приветствуются на GitHub.
