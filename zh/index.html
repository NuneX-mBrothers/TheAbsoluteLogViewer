不只是 .log——任何文本日志

Linux 和 Unix 日志形式各异：syslog、messages、轮转后的 auth.log.1，甚至没有扩展名的文件。设置文件匹配模式，即可跟踪所有匹配的文本文件——二进制文件会被自动排除。

每个标签页都是独立的工作区——拥有各自的日志集、分栏、搜索与排序。同时监视不同项目而互不混淆。

分屏对比

常见问题

真的免费吗？

是的——免费软件，可用于个人和商业用途。无需账户、无 Cookie；应用仅发送匿名的安装和更新统计，且可关闭。

打开时 Windows 要求确认，为什么？

签名较新，Windows 需要一段时间才会认识新的发布者——这与文件本身无关。点击“更多信息”→“仍要运行”。ClickOnce 安装保留自己的签名，仍可能显示“未知发布者”。每个版本都会公布可核对的 SHA-256。

我该选哪个版本？

想要轻松自动更新就选 ClickOnce（需要 Microsoft Edge）。已装 .NET 10 运行时就选 Standalone。想要免安装就选 Portable。

源代码在哪里？

应用为免费软件，源代码不公开，但欢迎在 GitHub 提交错误报告和功能请求。
