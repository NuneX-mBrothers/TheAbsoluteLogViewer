每一個下載都可以驗證

Standalone 與 Portable 的下載都經過數位簽章，並附有時間戳記。每個版本也會在 version.json 中公開 SHA-256，程式透過 HTTPS 安裝任何更新前都會先比對。被竄改的檔案會自動遭到拒絕。

而且不必只聽我們說：Softpedia Labs 獨立測試後，給了 100% Clean 標章 — 沒有間諜軟體、廣告軟體或病毒。
為每天與日誌為伍的人而做

tail -f 讓你想要卻沒有的，這裡都有。

不只是 .log — 任何文字日誌都可以

Linux 與 Unix 的日誌形形色色：syslog、messages、輪替過的 auth.log.1，甚至完全沒有副檔名的檔案。給它檔名比對模式，它就會追蹤每一個符合的文字檔 — 二進位檔會自動略過。

即時日誌追蹤

即時跟著日誌檔跑 — 新的行立刻出現。向上捲動就暫停，回到底部就繼續。

獨立分頁

每個分頁都是自己的工作區：有自己的日誌組合、分割、搜尋與排序。同時盯著不同專案，而不會混在一起。

分割視窗比對

兩個獨立的窗格、兩個並排的檔案 — 各有各的搜尋與追蹤。

以欄位追蹤 .csv

.csv/.tsv 也行，而且以表格顯示 — 檔案的標題列變成欄位名稱，新的列即時出現。逗號、分號或 Tab 會自動判斷。

正規表示式標示規則

整行或單一字詞都能上色。附有字詞邊界輔助與即時預覽。

前後文預覽

把游標移到篩選後的某一行，就能看到未篩選完整檔案中它前後的內容。

內建自動更新

Standalone 與 Portable 會自行更新 — 透過 HTTPS 檢查完整性。

常見問題

真的免費嗎？

是的 — 免費軟體，個人與商業用途都可以。不需要帳號，也沒有 Cookie；程式只會送出匿名的安裝與更新統計，而且可以關掉。

開啟時 Windows 要我確認，為什麼？

簽章還很新，Windows 需要一段時間才會認得新的發行者 — 這不是檔案的問題。請點「其他資訊」→「仍要執行」。ClickOnce 安裝使用自己的簽章，可能仍會顯示「不明的發行者」。每個版本都會公開可供比對的 SHA-256。

我該選哪一個版本？

想要毫不費力的自動更新就選 ClickOnce（需要 Microsoft Edge）。已經有 .NET 10 執行環境就選 Standalone。什麼都不想安裝就選 Portable。

原始碼在哪裡？

程式是免費軟體，原始碼並未公開，但歡迎在 GitHub 上回報問題或提出功能建議。
