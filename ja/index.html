どのダウンロードも検証できます

Standalone と Portable のダウンロードには、タイムスタンプ付きのデジタル署名があります。各リリースは version.json に SHA-256 を公開し、アプリは HTTPS 経由で更新を入れる前にそれを照合します。改ざんされたファイルは自動的に拒否されます。

しかも、私たちの言葉を信じる必要はありません。Softpedia Labs が独自に検査し、100% Clean — スパイウェア・アドウェア・ウイルスなし — と認定しました。

.log だけではありません — どんなテキストログでも

Linux と Unix のログは形がさまざまです：syslog、messages、ローテーションされた auth.log.1、拡張子のまったくないファイル。ファイル名のパターンを渡せば、一致するテキストファイルをすべて追跡します — バイナリは自動的に除外されます。

リアルタイムのログ追跡

ログファイルをライブで追跡 — 新しい行がすぐに流れてきます。上にスクロールすると一時停止、最後に戻ると再開します。

独立したタブ

タブごとに独立した作業場です。ログの組み合わせ、分割、検索、並び順をそれぞれが持ちます。別々のプロジェクトを混ぜずに同時に見られます。

分割表示で比較

独立した 2 つのペインに、2 つのファイルを並べて — それぞれに検索と追跡があります。

.csv を列で追跡

.csv/.tsv も、表として表示します — ファイルのヘッダーが列名になり、新しい行がライブで現れます。カンマ、セミコロン、タブは自動で判別します。

正規表現のハイライト

行全体でも、単語ひとつでも色を付けられます。単語境界の補助とライブプレビュー付き。

前後のプレビュー

絞り込んだ行にカーソルを合わせると、絞り込む前のファイルから前後の行が見えます。

自動更新を内蔵

Standalone と Portable は自分で更新します — HTTPS 経由で整合性を確認します。

よくある質問

本当に無料ですか？

はい — フリーウェアで、個人でも商用でも使えます。アカウントも Cookie もありません。アプリが送るのは匿名のインストールと更新の統計だけで、それも切ることができます。

開くときに Windows が確認を求めます。なぜですか？

署名が新しく、Windows が新しい発行元を認識するには時間がかかります — ファイルの問題ではありません。「詳細情報」→「実行」を選んでください。ClickOnce のインストールは独自の署名を使うため、「不明な発行元」と表示されることがあります。各リリースでは、確認できる SHA-256 を公開しています。

どの版を選べばいいですか？

手間なく自動更新したいなら ClickOnce（Microsoft Edge が必要です）。.NET 10 がすでに入っているなら Standalone。何もインストールしたくないなら Portable。

ソースコードはどこですか？

アプリはフリーウェアで、ソースは非公開です。不具合の報告や機能の要望は GitHub で歓迎しています。
